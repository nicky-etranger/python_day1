## Создание

При создании BankAccount:

1. Проверяется имя владельца
2. Проверяется начальный баланс
3. Проверяется статус счёта
4. Проверяется валюта
5. Если account_id отсутствует, автоматически создаётся короткий UUID
6. Данные сохраняются в объекте счёта

## Пополнение

При вызове deposit(amount):

1. Проверяется статус счёта
2. Проверяется корректность суммы
3. Сумма добавляется к текущему балансу
4. Возвращается новый баланс

Операция запрещена для замороженного и закрытого счёта

## Снятие

При вызове withdraw(amount):

1. Проверяется статус счёта
2. Проверяется корректность суммы
3. Проверяется наличие достаточного количества средств
4. Сумма вычитается из баланса
5. Возвращается новый баланс

Если денег недостаточно, вызывается InsufficientFundsError

Операция запрещена для замороженного и закрытого счёта
